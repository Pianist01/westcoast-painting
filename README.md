# HLF Painting & Finishing

This is a responsive multi-page website developed for HLF Painting & Finishing, a professional painting business.

OVERVIEW

This site was designed and developed as a freelance project with the purpose of establishing an online presence for HLF Painting while also providing potential clients with information about the company, its services, and a way to get in contact.

FEATURES

- Fully Responsive Design
- Multi-page website
- Interactive service details
- Scroll-based animations
- Contact form with EmailJS integration
- Mobile-friendly navigation
- Custom Domain

BUILT WITH

- HTML5
- CSS3
- JavaScript
- EmailJS
- Git/GitHub
- GitHub Pages

PAGES

- Home
- Services
- About Us
- Contact

What I Learned

This project gave me experience developing and deploying a website for a real client. This included translating client requirements into a responsive interface, and testing across multiple viewport sizes and devices, and also implementing interactive JavaScript features.
